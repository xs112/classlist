# 矿大课表

一个面向中国矿业大学（北京）研究生信息管理系统的简单 Android 课表 App。

## 使用

1. 安装 `app/build/outputs/apk/debug/app-debug.apk`。
2. 点击“进入并导入”；App 会从研究生院官网进入“研究生信息管理系统”。
3. 在学校统一身份认证页面完成登录，进入管理系统后点击右上角“导入”。
4. 导入后可按星期和周次查看课程；“同步”会重新打开校方系统。

App 打开时会根据中国标准时间自动选择当前教学周和星期，并定位当天正在上课或下一节课程。“今天”按钮可随时返回当前位置。当前教学周换算依据学校发布的 2026-2027 学年教学日历；寒暑假期间显示全部周次。

登录由学校统一身份认证网页处理。App 不读取或保存密码、验证码，仅在应用私有目录中保存解析后的课程，且已关闭系统备份。

若显示连接超时，请检查校园网或学校 VPN。错误页可直接重试或在系统浏览器打开研究生院官网。

## 构建

项目要求 JDK 17 或更新版本和 Android SDK：

```powershell
.\gradlew.bat lintDebug testDebugUnitTest assembleDebug
```

## 兼容性说明

校方系统没有公开课表 API，本项目通过登录后的同源网页读取课表表格。若学校调整菜单名称或 HTML 表格结构，需要同步更新 `PortalExtractor` 或 `ScheduleParser`。
